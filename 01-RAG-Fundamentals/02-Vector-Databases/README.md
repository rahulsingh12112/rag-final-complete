# Vector Databases - Pinecone, ChromaDB, pgvector, Weaviate

## What are Vector Databases?
Embeddings store karne aur efficiently nearest-neighbor search karne ke liye specialized databases.

## Learn:
- [ ] ChromaDB (local, prototyping)
- [ ] Pinecone (managed, production)
- [ ] pgvector (PostgreSQL extension)
- [ ] Weaviate (hybrid search built-in)
- [ ] Indexing strategies (HNSW, IVF)
- [ ] Distance metrics (cosine, euclidean, dot product)
