# Chunking Strategies

## Why Chunking?
LLMs ki context window limited hai. Documents ko chhote meaningful pieces mein todna padta hai.

## Learn:
- [ ] Fixed-size chunking (500-1000 tokens, with overlap)
- [ ] Recursive character splitting (LangChain default)
- [ ] Semantic chunking (meaning-based boundaries)
- [ ] Document-based chunking (headings, sections respect karna)
- [ ] Chunk size vs accuracy tradeoff

## Practice:
- [ ] Same document ko different strategies se chunk karo
- [ ] Chunk overlap ka impact test karo
- [ ] Best chunk size find karo for your use case
