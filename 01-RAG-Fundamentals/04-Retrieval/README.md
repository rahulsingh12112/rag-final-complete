## What is Retrieval?

## Learn:

- [ ] MMR - Maximum Marginal Relevance (relevance + diversity)
- [ ] Top-k selection (kitne chunks retrieve karne hain?)
- [ ] Threshold-based filtering (minimum similarity score)
- [ ] Hybrid retrieval (keyword + semantic)
